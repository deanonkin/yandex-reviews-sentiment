# Анализ отзывов «Вкусно — и точка» с Яндекс.Карт

Автоматический пайплайн, который собирает отзывы с Яндекс.Карт, 
анализирует их с помощью NLP и показывает результаты на интерактивном 
дашборде.

**Дашборд:** https://a6648ab6.us2a.app.preset.io/superset/dashboard/p/0xDpg7V87W4/

![Общий вид дашборда](docs/dashboard1.pdf)

---

## 🎯 Зачем это нужно

У сети из 10 ресторанов сотни отзывов на Яндекс.Картах. Читать их вручную 
каждый день — долго и неэффективно. Нужен инструмент, который сам:

- собирает свежие отзывы;
- понимает, на что жалуются гости (еда, обслуживание, чистота, цена, скорость);
- показывает картину по всем заведениям сети на одном экране.

Этот проект решает задачу «от сбора данных до дашборда» полностью 
автоматически.

---

## 🔄 Как это работает

**Шаг 1. Сбор отзывов.**  
Скрипт на Python (Playwright) заходит на Яндекс.Карты, собирает по 50 
последних отзывов с 10 заведений сети.

**Шаг 2. Перевод.**  
Отзывы на русском переводятся на английский моделью MarianMT. Это нужно, 
потому что open-source модели анализа тональности лучше работают с английским.

**Шаг 3. Анализ тональности по аспектам.**  
Для каждого отзыва модель DeBERTa определяет тональность по 5 аспектам: 
еда, обслуживание, чистота, цена, скорость. То есть один отзыв превращается 
в 5 оценок: «еда — позитив», «чистота — негатив» и т.д.

**Шаг 4. Загрузка в базу данных.**  
Результаты складываются в PostgreSQL (Supabase). Пайплайн проверяет дубли 
и добавляет только новые отзывы — база растёт накопительно, старые данные 
не теряются.

**Шаг 5. Дашборд.**  
Данные автоматически подтягиваются в Apache Superset, где построен 
интерактивный дашборд для операционного директора сети.

**Всё это работает само:** раз в сутки GitHub Actions запускает пайплайн 
в Docker-контейнере, и дашборд всегда показывает свежую картину.

## 📊 Что показывает дашборд

### KPI-строка
Всего отзывов, средний рейтинг, доля негатива, топ-проблема сети.

### Рейтинг по заведениям
Bar chart: какие точки отличники, а какие — проблемные.

### Тепловая карта «Заведение × Аспект»
Видно, где именно болит: у одного ресторана — грязь, у другого — очереди, 
у третьего — хамство персонала.

![Тепловая карта](docs/heatmap.png)

### Тональность по аспектам
Stacked bar: доля позитива, нейтрала и негатива по каждому аспекту 
(еда, обслуживание, чистота, цена, скорость).

### Тренд рейтинга
Line chart: как меняется средний рейтинг сети по неделям.

### Последние отзывы
Таблица из 10 свежих отзывов, где для каждого в одной строке видны 
оценки по всем 5 аспектам.

![Последние отзывы](docs/last_reviews.png)

## 🛠 Что использовал

| Что | Зачем |
|-----|-------|
| Python + Playwright | Парсинг Яндекс.Карт |
| Transformers (MarianMT, DeBERTa) | Перевод и анализ тональности |
| PostgreSQL (Supabase) | Хранение данных |
| Apache Superset (Preset Cloud) | Визуализация |
| GitHub Actions + Docker | Автоматизация запуска |

---

## 📈 Результаты

- Собрано **500+ отзывов** с 10 заведений.
- Выявлена главная проблема сети: **скорость обслуживания** — 
  ~50% негативных упоминаний.
- Построен дашборд, который обновляется автоматически и показывает 
  свежие данные.

---

## ⚠️ Честные ограничения

- Парсер видит только топ-50 отзывов на заведение — Яндекс не отдаёт 
  больше без авторизации.
- Перевод RU→EN иногда теряет нюансы (сарказм, сленг) — около 20% 
  отзывов могут обрабатываться с ошибками.
- Модель анализа тональности обучена на английском, поэтому качество 
  на русских отзывах не идеальное, но для дашборда достаточно.
