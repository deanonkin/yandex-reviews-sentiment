# Анализ отзывов «Вкусно — и точка» с Яндекс.Карт

Автоматический пайплайн, который собирает отзывы с Яндекс.Карт, 
анализирует их с помощью NLP и показывает результаты на интерактивном 
дашборде в Apache Superset.

**Дашборд:** [docs/dashboard1.pdf](docs/dashboard1.pdf)

---

## 🎯 Зачем это нужно

У сети из 10 ресторанов сотни отзывов на Яндекс.Картах. Читать их 
вручную каждый день — долго и неэффективно. Нужен инструмент, который сам:

- собирает свежие отзывы;
- понимает, на что жалуются гости (еда, обслуживание, чистота, цена, скорость);
- показывает картину по всей сети на одном экране.

Этот проект решает задачу «от сбора данных до дашборда» полностью 
автоматически.

---

## 🔄 Как это работает

**1. Сбор отзывов.**  
Скрипт на Python (Playwright) заходит на Яндекс.Карты и собирает 
по 50 последних отзывов с 10 заведений сети.

**2. Перевод.**  
Отзывы переводятся на английский моделью MarianMT. Это нужно, 
потому что модели анализа тональности лучше работают с английским.

**3. Анализ тональности по аспектам.**  
Модель DeBERTa для каждого отзыва определяет тональность по 5 аспектам: 
еда, обслуживание, чистота, цена, скорость. Один отзыв превращается 
в 5 оценок: «еда — позитив», «чистота — негатив» и т.д.

**4. Загрузка в базу.**  
Результаты складываются в PostgreSQL (Supabase). Пайплайн проверяет дубли 
и добавляет только новые отзывы — база растёт накопительно.

**5. Дашборд.**  
Данные подтягиваются в Apache Superset, где построен интерактивный 
дашборд для операционного директора сети.

**Всё работает автоматически:** раз в сутки GitHub Actions запускает 
пайплайн в Docker-контейнере.

## 📊 Что показывает дашборд

### KPI (Big Numbers)
- **Объём выборки** — сколько отзывов проанализировано.
- **Количество групп** — сколько заведений в анализе.
- **Средний рейтинг** — по всей сети, с графиком динамики.
- **Процент негативных упоминаний** — доля негатива среди всех 
  упоминаний аспектов, с графиком.

### Bar charts
- **Средний рейтинг по заведениям** — сравнение точек сети.
- **Средний рейтинг по дням недели** — выявляет проблемные дни.
- **Кол-во позитивных / негативных оценок и общее кол-во упоминаний 
  по аспектам** — картина по 5 темам (еда, обслуживание, чистота, цена, 
  скорость).
- **Количество отзывов по дням** — динамика активности гостей.

### Сводные таблицы (Pivot Tables)
- **Количество негативных отзывов по заведениям и аспектам** — 
  где и что болит сильнее всего.
- **Количество позитивных отзывов по заведениям и аспектам** — 
  где и что хвалят.

### Line chart
- **Динамика среднего рейтинга по заведениям поквартально** — 
  кто улучшается, а кто сдаёт позиции.

### Таблица
- **Последние 50 отзывов** — для оперативного разбора свежих жалоб.

## 🛠 Что использовал

| Что | Зачем |
|-----|-------|
| Python + Playwright | Парсинг Яндекс.Карт |
| Transformers (MarianMT, DeBERTa) | Перевод и анализ тональности |
| PostgreSQL (Supabase) | Хранение данных |
| Apache Superset (Preset Cloud) | Дашборд |
| GitHub Actions + Docker | Автоматизация |

---

## 📈 Результаты

- Собрано **500+ отзывов** с 10 заведений сети.
- Выявлена главная проблема сети: **скорость обслуживания** — 
  ~50% негативных упоминаний.
- Построен дашборд, который обновляется автоматически.

---

## ⚠️ Ограничения

- Парсер видит только топ-50 отзывов на заведение — Яндекс не отдаёт 
  больше без авторизации.
- Перевод RU→EN иногда теряет нюансы (сарказм, сленг) — около 20% 
  отзывов могут обрабатываться с ошибками.
